# apache seatunnel web 部署

<PostMeta />

官网下载 seatunnel bin 版本
启动服务：

```shell
cd apache-seatunnel-2.3.11 & sh bin/seatunnel-cluster.sh -d
```
下载 web 源码：

```shell
git clone https://github.com/apache/seatunnel-web.git
```
